# THIRD-PARTY ASSETS

## Art, audio, fonts and data: none

This project contains **no third-party art, audio, model, texture, font, icon
or data assets of any kind**.

Every mesh, texture, animation and sound is generated by code at runtime. See
[docs/ASSET_PIPELINE.md](docs/ASSET_PIPELINE.md).

Concretely, the repository contains no model, audio or font binaries at all —
`git ls-files` returns no `.fbx`, `.obj`, `.glb`, `.gltf`, `.dae`, `.blend`,
`.wav`, `.mp3`, `.ogg`, `.flac`, `.ttf`, `.otf` or `.woff` files, and no image
that the game loads.

The only images in version control are the four screenshots in `docs/images/`,
used in the README. They are renders of this project's own output, captured by
`node tools/shots.mjs`; nothing in the game reads them. Screenshots produced by
the test tools go to `screenshots/`, which is git-ignored.

**Nothing in this project is derived from, extracted from, or based on assets
from any other game.**

## Verifying this claim

```bash
# No models, audio or fonts anywhere in version control, and no image the
# game loads (the only matches are the four README screenshots under docs/):
git ls-files | grep -Ei '\.(png|jpe?g|gif|svg|bmp|webp|tga|fbx|obj|glb|gltf|dae|blend|wav|mp3|ogg|flac|aiff|ttf|otf|woff2?)$'
# (expected: only docs/images/*.png)

# Nothing in the source ever loads an asset file:
grep -rEn "TextureLoader|GLTFLoader|FBXLoader|AudioLoader|FontLoader|fetch\(.*\.(png|jpg|wav|mp3|glb)" src/
# (expected: no output)

# Everything shipped is either source or the three.js bundle:
npm run build && ls dist/assets/
```
